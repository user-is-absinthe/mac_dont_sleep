# Mac не спит

[🇬🇧 English](README.en.md)

![Иконка приложения: чашка кофе](Resources/AppIcon.png)

Небольшое нативное macOS-приложение, которое не даёт вашему Mac уснуть в течение выбранного времени. Это удобный интерфейс для встроенной утилиты [`caffeinate`](https://ss64.com/mac/caffeinate.html) — без фоновых служб, пакетов Homebrew и сторонних утилит для уведомлений.

## Возможности

- Любая длительность в целых минутах, плюс быстрые кнопки на 15, 30, 60 и 120 минут.
- Живой обратный отсчёт и точное локальное время окончания.
- Режим «держать Mac включённым, но позволить экрану гаснуть» (`caffeinate -i`) или «держать включёнными и Mac, и экран» (`caffeinate -di`).
- Отмена таймера в любой момент.
- Безопасная остановка дочернего процесса `caffeinate` при выходе через <kbd>⌘Q</kbd>.
- Нативное уведомление macOS по завершении таймера.
- Универсальный бинарник для Mac на Apple Silicon и Intel.

## Требования

- macOS 13 Ventura или новее
- Apple Command Line Tools (`xcode-select --install`)

## Скачивание

Готовую сборку можно скачать со страницы [Releases](https://github.com/user-is-absinthe/mac_dont_sleep/releases). Откройте скачанный DMG-образ и перетащите приложение на ярлык **Applications** рядом — оно попадёт в «Программы». Собирать проект самостоятельно не обязательно.

Приложение подписано ad-hoc-подписью (без Apple Developer ID), поэтому при первом запуске скачанной копии macOS может показать предупреждение системы безопасности Gatekeeper. Снимите карантин командой:

```zsh
xattr -cr "/Applications/Don't sleep.app"
```

## Сборка и запуск

1. Склонируйте или скачайте этот репозиторий.
2. В Finder дважды щёлкните файл [`build_app.command`](build_app.command) или выполните в терминале:

   ```zsh
   ./build_app.command
   ```

3. Откройте собранное приложение:

   ```text
   build/Don't sleep.app
   ```

При первом запуске таймера macOS запросит разрешение на отправку уведомлений. Отказ не повлияет на удержание от сна и обратный отсчёт — будет отключено только уведомление о завершении.

## Как это работает

Приложение запускает встроенную команду `caffeinate` с таймаутом. Переключатель **Держать экран включённым** управляет флагами команды:

| Переключатель | Флаги | Эффект |
| --- | --- | --- |
| Выкл. | `-i` | Отменяет системный сон по простою; экран может гаснуть как обычно. |
| Вкл. | `-di` | Отменяет и системный сон по простою, и выключение экрана. |

Приложение владеет дочерним процессом. Отмена таймера или выход из приложения немедленно завершает процесс, возвращая macOS обычные настройки энергосбережения.
